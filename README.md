# Model 67 (from scratch)

This repo contains a working **Model67** built from scratch in pure Python.

- `model67.py`: A 67-feature linear regression model with manual gradient descent.
- `test_model67.py`: A unit test proving the model learns on synthetic data.

## Run

```bash
python model67.py
python -m unittest -v
```

The demo prints training MSE before/after and test R².
